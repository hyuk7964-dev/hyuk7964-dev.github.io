오픈AI, 송재경과 함께하는 '오픈AI 게임 빌더스 서울' 8월 31일 개최

코덱스 게임 개발 해커톤 첫 개최로 무너지는 제작 장벽

요약

오픈AI가 8월 31일 서울에서 코딩 에이전트 ’코덱스’를 활용한 게임 개발 해커톤 ’오픈AI 게임 빌더스 서울’을 개최한다. 오픈AI가 코덱스 기반 게임 개발을 주제로 전 세계에서 처음 여는 행사이며, 송재경 개발자가 참여해 코덱스로 게임 개발 현장에 복귀하는 여정을 공유한다. 컴투스 ’하이브’와 연동하는 새로운 개발 모델을 제안하며, 심사를 통과한 40개 팀이 초청되고 우수팀에게는 총 5만 달러 상당의 API 크레딧 등이 제공된다.

나의 생각

“오픈AI가 ’코덱스’를 활용한 게임 개발을 주제로 전 세계에서 처음 여는 행사”라는 점과, 리니지·바람의나라를 만든 송재경이 코덱스로 다시 개발 현장에 복귀한다는 이야기가 인상 깊었다. AI 코딩 도구가 이제 프로토타입 제작을 넘어 실제 서비스 연동(로그인·결제·유저분석)까지 5시간 만에 구현해볼 수 있는 수준이 됐다는 건, 앞으로 사업PM도 개발 리소스를 기다리지 않고 직접 아이디어를 검증해볼 수 있는 시대가 온다는 뜻이라 생각한다. 나 역시 이번 포트폴리오 작업에서 AI 툴로 자료조사·분석·문서화를 직접 해본 경험이 이런 흐름과 맞닿아 있다고 느꼈다.

셀프 Q&A

Q. 이 행사가 갖는 '최초' 타이틀은?

A. 오픈AI가 코덱스 기반 게임 개발을 주제로 전 세계에서 처음 여는 행사.

Q. 코덱스와 하이브는 각각 무엇이고 왜 함께 언급되나?

A. 코덱스=자연어 기반 코딩 에이전트(제작 단계), 하이브=컴투스의 게임 백엔드 플랫폼으로 로그인·결제·유저분석·보안 지원(운영 단계). “코덱스로 빌드, 하이브로 플레이”는 제작과 서비스 운영을 하나의 파이프라인으로 묶는 모델.

Q. 참가 구조와 보상 규모는?

A. 4~26일 신청 → 심사 통과 40개 팀 초청 → 트랙1(사전 제작작 발표)/트랙2(5시간 해커톤) → 트랙1 우수팀은 API 크레딧 5만 달러 + 챗GPT 프로 1년, 본선 참가자 전원 API 크레딧 100달러.

Q. (사업PM 관점) 이 행사가 보여주는 흐름의 반대급부(리스크)는?

A. 5시간 만에 로그인·결제까지 붙는다는 건 진입장벽이 낮아진다는 뜻이지만, 김용하 PD 기사의 “스팀 신작 절반이 리뷰 10개 미만” 통계처럼 ’만들기 쉬움’이 곧 ’경쟁 심화’로 이어질 수 있음 — 오픈AI/김용하/요시다 세 기사를 관통하는 공통 리스크.
