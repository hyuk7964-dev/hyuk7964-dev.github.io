게임 백과사전 · 04

온보딩 / 진입장벽

진입장벽이 생기는 지점 (시간순 프레임)

시스템 학습 부담

  • 고유 성장 시스템이 복잡할수록 유튜브·커뮤니티 의존이 커짐.
  • 사례: 명조 에코 시스템(코스트 조합 + 서브옵션 RNG + 공효 우선순위)이 압도적 1위 학습 장벽 — 가이드 제작자도 “다 못 담았다”고 인정.

파티/덱 구성 장벽

  • 역할(딜·서브딜·서포터) 분업이 필수인데 인게임에서 조합 정보를 주지 않으면 커뮤니티로 나감.
  • 사례: 명조 — 아카라이브에 하루 ~10건 파티 편성 질문. 완전한 3인 파티 구성이 뉴비의 벽.

“뉴비 사다리” 부재

  • 후반 지역에 육성 재료가 몰려 있으면 늦게 온 유저가 따라잡을 사다리가 없음.

초반 콘텐츠 품질 격차

  • 시작 지역의 필드 디자인·연출이 이후 지역보다 떨어지면 첫인상에서 이탈.

개선 레버 (PM이 설계 가능한 것)

  • 신규 패키지에 역할별 확정 선택권 제공 → 즉시 파티 완성 → DAU·잔존율 상승 (명조 “공명 파티 스타터 패키지” 제안)
  • 1장 마지막 스토리 완료 시점에 팝업으로 노출 (도달률 높은 트리거 지점)
  • 가이드 콘텐츠가 정작 기존 유저에게만 도달하는 문제 → 인게임 내 노출 필요

복귀 유저

  • 복귀 실패 트리거: 픽뚫 과금 기억, 느린 맵 이동, 이벤트 스토리 영구 소실 등.

복귀의 최대 장벽은 콘텐츠 부족이 아니라 “지금 들어가면 손해”라는 계산

  • 격차가 벌어진 게임에 돌아가는 유저는 콘텐츠 양보다 따라잡는 비용을 먼저 계산한다. 이 계산을 줄이는 레버는 강도 순으로: 뉴비·복귀 사다리 → 복귀 전용 적응 과정 → 진척도 전원 초기화(가장 비싸고 가장 확실).
  • 초기화의 대가: 남아 있던 코어 유저가 누적 자산을 잃는다 — 가장 충성한 사람이 가장 많이 잃는 구조라, 이들에게 따로 보상하지 않으면 복귀 유저를 얻는 대신 코어를 잃는다.
  • 경쟁 모드(랭크)는 인원이 적을 때 독이 된다 — 상위권만 남고 하위권은 매칭마다 압도당해 이탈이 가속. 랭크 보류 = “코어의 경쟁 욕구보다 풀 전체의 크기가 먼저”라는 우선순위 선언.
  • 복귀 결정은 한 번의 이벤트가 아니라 “지금 돌아오면 무엇을 받는지 + 앞으로 언제 무엇이 오는지” 를 함께 보여줄 때 몇 달짜리 약속이 된다(분할 로드맵 공개). 대신 일정을 한 번이라도 어기면 신뢰가 그대로 깎인다.
  • 사례: 번지 마라톤(익스트랙션 슈터, 2026-03 출시) — 10월 진척도 초기화·랭크전 보류·PvE 순환 → 12월 신규 입문 과정 개편 → 3월 복귀 유저 적응 과정. 근거: 뉴스 카드 2026-09-25.
  • 사례: 에노키안의 전설(대만 장수작) — 소환권·한정 캐릭터·미니게임을 한 이벤트에 묶어 복귀 동선을 만들고 모바일 4위로 복귀. 근거: 뉴스 카드 2026-09-25 「8월 대만 게임 시장 동향」.
